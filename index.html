framing · decomposition · verification

Profile

I design and build systems where an LLM works inside a production process: n8n + PostgreSQL/pgvector orchestration, Python bots and services, media-generation pipelines. Claude Code, the OpenAI and Gemini APIs are my primary development tools — code, migrations, workflows and documentation are born in a dialogue with a model and then checked by linters, tests and measurements on a stand.

My view: AI is the next compiler after assembly and high-level languages. Translating human language into a program means translating from a domain of high ambiguity into a domain of zero tolerance for paradox, and that translation is what I consider my actual job. Hence the core skills: problem framing, decomposition, control of invariants, verification of the result — while the programming language stays a tool that changes from project to project.

All the projects below live in private repositories under NDA; the code is not published, and I discuss architecture at the interview within what I am allowed to say. A detailed technical CV is available on request.
